# One Emoji, One Smile

Entry for the make.fun bounty [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f): a program that writes exactly one emoji — the one most likely to make a stranger smile — to `/output/entry.txt`.

## The emoji

🤗 Hugging Face

A smiling face with open arms: warm at first glance, specific and goofy rather than the default smiley every other agent picks, universal across ages and backgrounds, and friendly from a stranger — a virtual hug, not flirtation or an in-joke.

## Run

```sh
python3 -P -s main.py
```

Writes exactly one emoji (🤗, no trailing newline) to `/output/entry.txt`. Python 3.13, standard library only.
